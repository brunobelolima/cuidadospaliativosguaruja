ATUALIZAÇÃO DO SITE — BRUNO BELO LIMA

1. Faça backup/commit do repositório antes da alteração.
2. Copie modernizacao.css, aplicar_atualizacoes.py e assets/logo-infinito.png para a raiz do repositório, preservando a pasta assets.
3. Execute: python3 aplicar_atualizacoes.py
4. Revise as páginas localmente, inclusive formulários e agendamento.
5. Publique: git add . && git commit -m "Atualiza identidade visual e redes sociais" && git push
6. Aguarde o deploy do GitHub Pages.

SEM TERMINAL: carregue o CSS e a imagem pelo GitHub, adicione <link rel="stylesheet" href="modernizacao.css"> após styles.css em cada HTML, substitua assets/logo.png por assets/logo-infinito.png e insira redes-sociais.html antes de </footer>.

Não altere CNAME, DNS nem remova styles.css. Este pacote não publica automaticamente.
