PROGRAMA DE ACOMPANHAMENTO PALIATIVO — GITHUB

Este pacote foi preparado para o repositório brunobelolima/cuidadospaliativos.

1. No GitHub, clique em Code > Download ZIP e extraia a pasta.
2. Copie separar_programa.py para a mesma pasta de index.html e styles.css.
3. Abra o Terminal nessa pasta e execute: python3 separar_programa.py
4. Serão gerados/alterados:
   - index.html: retira o programa da página inicial e altera o menu;
   - programa.html: nova página interna com todo o conteúdo original;
   - index.antes-programa.html: backup LOCAL, não publicar.
5. Confira os preços e serviços. Depois envie APENAS index.html e programa.html
   para a raiz do repositório no GitHub (Add file > Upload files).
6. Aguarde a publicação pelo GitHub Pages.

Endereço esperado:
https://brunobelolima.github.io/cuidadospaliativos/programa.html

O script não altera preços, descrições ou demais serviços: usa o conteúdo do
index.html existente no momento da execução.
